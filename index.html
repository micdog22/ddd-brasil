DDD Brasil

Consulte os 67 DDDs do Brasil e valide números de telefone.

Consultar DDD

Ex.: 19, Limeira, SP ou Minas Gerais. A busca por cidade considera as principais cidades de cada DDD.

Validar telefone

Celular, fixo, 0800 ou serviço (190, 192…). Pode incluir +55 ou o 0 da operadora.

Todos os DDDs por região

Use no seu projeto

Biblioteca JavaScript sem dependências, para Node.js e navegador, com linha de comando.

npm install github:micdog22/ddd-brasil

import { buscarDDD, buscarCidade, validarTelefone } from 'ddd-brasil';

buscarDDD(19).cidades;           // ['Campinas', 'Piracicaba', 'Limeira', ...]
buscarCidade('limeira');         // [{ cidade: 'Limeira', uf: 'SP', estado: 'São Paulo', ddd: 19 }]
validarTelefone('19999999999');  // { valido: true, tipo: 'celular', formatado: '(19) 99999-9999', ... }
